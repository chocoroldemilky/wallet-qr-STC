# Pruebas criptográficas

## Objetivo
Verificar la corrección de las operaciones criptográficas
y el manejo seguro de los datos.

## Pruebas previstas
- Vectores de prueba conocidos para HMAC-SHA256.
- Cifrado y descifrado mediante AES-GCM.
- Detección de modificaciones en datos cifrados.
- Validación de firmas digitales de boletos.
- Verificación del manejo de claves y errores criptográficos.
