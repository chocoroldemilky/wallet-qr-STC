# Plan de pruebas

## Objetivo
Definir el alcance, los casos de prueba y los criterios de aceptación
para la aplicación Wallet del Usuario y QR Dinámico Anticopia.

## Categorías
- Pruebas funcionales.
- Pruebas criptográficas.
- Pruebas de integración.
- Pruebas de regresión.
- Pruebas de seguridad y almacenamiento local.

## Registro de resultados
Cada prueba deberá incluir identificador, precondiciones,
datos de entrada, pasos, resultado esperado, resultado obtenido
y estado final.

## Estado
Pendiente de implementación y ejecución.
